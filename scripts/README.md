# Reference Scripts & Training Storage

This directory contains preserved reference scripts from the original WACV 2025 research codebase for dataset preparation, model training, and academic evaluation.

## Contents

- **`training/SAC/`**: Segmentation and Cross-Association (SAC) model training code (modified YOLOv8 architecture).
- **`training/HNH/`**: Data extraction and annotation scripts for Helmet / No-Helmet detection.
- **`training/ANPR/`**: License plate dataset annotation and extraction scripts.
- **`training/CA-SORT/`**: Original research tracking scripts and configuration.
- **`evaluation/`**: Academic evaluation scripts (`challan_rate_calc.py`, `tr_eval.py`, `hnh_eval.py`, etc.).
- **`dataset/`**: Instructions for downloading and preparing the RideSafe-400 dataset.
